SWIFS COMMENTS SHEET UPDATE

In Termux (install python once with: pkg install python):
  cd ~/swifs
  unzip -o ~/comments-update.zip
  python3 scripts/apply_comments.py
  git add -A
  git commit -m "Comments sheet with replies and heart animation"
  git push
