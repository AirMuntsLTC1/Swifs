SWIFS UPDATE - icons + splash (no white box, no Flutter logo)

Install (Termux):
  pkg install unzip -y
  cd ~/swifs            # your project folder (the one with app/ and .github/)
  unzip -o ~/swifs-update.zip
  git add -A
  git commit -m "Update icons and native splash"
  git push

Then uninstall the old Swifs app before installing the new APK.
